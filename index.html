Local model setup

Forge uses Ollama locally. For images, download a small vision model too; on this computer use qwen2.5vl:3b (about 3.2 GB). Voice uses local offline recognition and the installed Windows voice.
Download once in PowerShell: ollama pull qwen2.5vl:3b. Image understanding works after the vision model is installed. Scanned PDF OCR is not included.
